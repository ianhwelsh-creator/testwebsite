# Atelier - Luxury Men's E-Commerce Website

A premium luxury e-commerce website inspired by Mr Porter, featuring 50 curated products from world-renowned designers.

## ✨ Features

- **50 Luxury Products** across 6 categories (Outerwear, Knitwear, Shirts, Trousers, Shoes, Accessories)
- **Premium Brands**: Tom Ford, Brunello Cucinelli, Loro Piana, John Lobb, Common Projects
- **Complete E-Commerce Flow**: Browse → Product Detail → Add to Cart → Checkout → Order Confirmation
- **Advanced Filtering & Sorting**: Filter by brand, price; sort by price, newest, featured
- **Wishlist**: Save favorite items with persistent storage
- **Shopping Cart**: Full cart management with promo codes (WELCOME10, SALE20, LUXURY15)
- **Mock Checkout**: 3-step checkout flow with shipping, delivery, and payment UI
- **Account System**: Login, signup, profile, and order history (mock implementation)
- **Search**: Real-time product search
- **Responsive Design**: Optimized for mobile, tablet, and desktop
- **Luxury Aesthetic**: Clean typography, whitespace, neutral palette

## 🚀 Quick Start

```bash
npm install
npm run dev        # Development server
npm run build      # Production build
npm run preview    # Preview production build
```

## 🌐 Deployment

See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) for detailed Netlify deployment instructions.

**Quick Deploy**:
1. Run `npm run build`
2. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
3. Drag the `dist/` folder
4. Get your public URL!

- React 18 + Vite
- Tailwind CSS v3
- React Router v6
- Context API for state
- localStorage for persistence
